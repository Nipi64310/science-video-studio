# 开发与复现

统一入口 scripts/render.py 负责媒体路径、裁片段、缩放和 FFmpeg 编码。实例 renderer.py 只根据时间返回画面，DATA 保留已对齐的时间轴。

一分钟版保留自己的绘图基础；三分钟版沿用 graphics.py 并扩展明暗主题。这里先保留已验收实例，避免为了抽象而一次性改写全部画面逻辑。

新增主题建议复制一个实例到新目录，编写自己的画面逻辑和 timeline.json，再扩展 render.py 中的实例列表。不要只替换旧口播，却保留原游戏动作和时间轴。

字体使用随仓库提供的 Noto Sans SC 及其许可。截图不需要音轨，可用于新环境快速验证中文字体、Pillow 和路径。音频渲染必须有本地 master.wav，可用 prepare_demo_audio.py 从仓库中的案例视频准备工作音轨，也可从此前交付的工程 ZIP 导入原始音轨。

Qwen 转写入口为 scripts/asr_qwen.py，使用标准库和 DASHSCOPE_API_KEY；Filetrans 已验证返回句级、词级时间戳，参数和恢复方式见 [Qwen ASR 接入](Qwen-ASR接入.md)。asr_qwen.py 将毫秒时间戳转换为秒，输出 alignment.json 和待校对 SRT；此文件不是动画实例的 timeline.json。转写模型版本、运行平台和随机音频生成都可能影响新配音的时间。仓库中的时间轴只对应已交付声音。

测试只覆盖影响媒体正确性和密钥隔离的核心风险：WAV 头长度修复、秘密识别、生成成功后续下载不重复 POST，以及 Filetrans 任务恢复、失败处理、时间戳转换与范围检查。渲染用两个实例的短片段作实际检查，不要求每次整理文档都重跑整条视频。
