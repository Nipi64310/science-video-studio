# 验收办法

| 检查项 | 应检查什么 | 不能据此声称什么 |
|---|---|---|
| 事实 | 一手来源、日期、官方说法与推论分开 | 厂商宣传已被独立复现 |
| 台词 | 转写对原稿，是否整句缺失、重复或跑题 | 同音字识别正确就等于读音与听感全正确 |
| 声音 | 实际时长、截断、峰值、分段响度；有能力再试听音色 | API 接受参考音就代表完全复刻 |
| 字幕 | 时间来自声音，断句可读，无交叠或越界 | 按全文字数平摊也算精确同步 |
| 动画 | 选择→执行→结果；中间状态数值一致 | 几张漂亮截图就代表全片节奏合格 |
| 文件 | FFprobe 参数、FFmpeg 整片解码、首尾检查 | 成功写出 MP4 就代表内容完整 |
| 提交 | 暂存快照、媒体隔离、无秘密与临时地址 | 单个正则检查能发现所有敏感信息 |

三分钟版的历史验收记录在 examples/jev_3min/原版验收.md。那是原成片的检查，不自动适用于新主题或重新生成的配音。

没有音频感知能力时明确写“技术检查完成，主观试听未完成”，不要给自然度或相似度打虚构分数。
